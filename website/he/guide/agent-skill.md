# מיומנות לסוכן

מיומנות `mcp-gmap` הניידת מלמדת סוכן לבחור כלים, להפעיל MCP או CLI בבטחה, לבדוק כשלים חלקיים ולשמור על הייחוס ל-Google. היא משלימה את קובץ ההפעלה או את חיבור MCP שמגדירים בנפרד.

## התקנה מהמקור או מחבילת גרסה {#install-from-source-or-a-release}

חבילת המקור וכל ארכיון גרסה כוללים את [תיקיית המיומנות](https://github.com/fcenedes/mcp-gmap-rs/tree/main/skills/mcp-gmap). מתוך עותק של המאגר או ארכיון שחולץ, התקינו אותה עבור Codex:

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/mcp-gmap "${CODEX_HOME:-$HOME/.codex}/skills/"
```

הפעילו אותה בשם `$mcp-gmap`, לדוגמה:

> השתמש ב-$mcp-gmap כדי למצוא בתי קפה ליד Gare de Lyon, להשוות מסלולי הליכה ולשמור קישורים למקורות.

עבור סוכנים אחרים, מקמו את אותה תיקייה בספריית המיומנויות הנתמכת שלהם, או טענו את `SKILL.md` ואת ההפניות המקושרות. גוף ההוראות אינו תלוי בסוכן; `agents/openai.yaml` מספק מטא-נתונים אופציונליים לממשק Codex. התקינו קובץ הפעלה תקין ב-PATH של הסוכן או הגדירו את [חיבור MCP](./mcp).

## מה המיומנות מוסיפה {#what-the-skill-adds}

המיומנות מתחילה בגילוי כלים, ואינה מניחה שגרסה ישנה מותקנת מציגה את הקטלוג החדש ביותר. היא מעדיפה קואורדינטות מדויקות ומזהי מקומות שהוחזרו, מצמצמת את היקף החיפוש ובוחרת כלים ייעודיים לאימות כתובות, לספירה מצטברת ולחיפוש לאורך מסלול, במקום להסיק פעולות אלה מתוצאות לא קשורות.

היא מתייחסת לפרטי גישה כהגדרות תהליך או פריסה, ולא כארגומנטים לכלים. היא מבדילה בין הרשאת MCP נכנסת לגישה יוצאת ל-Google, ומתחילה באבחון לא מקוון. בדיקות חיות עשויות להיות כרוכות בתשלום. יש לבדוק שגיאות מקוננות בתוצאות משולבות גם כשהקריאה הראשית מצליחה.

[מדריך בחירת הכלים](https://github.com/fcenedes/mcp-gmap-rs/blob/main/skills/mcp-gmap/references/tool-selection.md) מסביר את כללי ההחלטה. [מדריך CLI](https://github.com/fcenedes/mcp-gmap-rs/blob/main/skills/mcp-gmap/references/cli.md) מכסה הפעלה מובנית ואבחון גישה. עיינו ב[מתכונים](./recipes) שבמדריך לתהליכי עבודה מלאים וב[מפרט הכלים](../reference/tools) לכל ארגומנט.
