# מפרט התצורה

21 הגדרות היישום האלה חלות על CLI, MCP stdio ו-Streamable HTTP לפי הצורך. סדר הערכים הוא **ברירות מחדל, dotenv אופציונלי, סביבה ואפשרויות**. ראו [תצורה](../guide/configuration) לבחירת קובץ ולמשמעות עקיפות.

אפשרויות כלליות מופיעות לפני כלי או `serve`; אפשרויות HTTP בלבד אחרי `serve http`. מקף בעמודת האפשרויות פירושו שאין אפשרות CLI מקבילה: הזריקו את הערך מהסביבה או מקובץ dotenv שנבחר.

## גישה ל-Google והרצת כלים {#google-access-and-tool-execution}

| משתנה | ברירת מחדל | אפשרות | משמעות וערכים מותרים |
| --- | --- | --- | --- |
| `GOOGLE_MAPS_API_KEY` | לא מוגדר | — | מפתח Google API מוגבל. נדרש במצב `api-key` ולנקודות קצה התומכות רק במפתח במימוש זה, גם כשנבחר OAuth. לעולם אינו ארגומנט לכלי. |
| `GOOGLE_MAPS_AUTH_MODE` | `api-key` | `--auth-mode` | הערכים `api-key` או `oauth`. OAuth תומך ב-Places (New), Routes, Weather, Air Quality, Address Validation ו-Places Aggregate. |
| `GOOGLE_APPLICATION_CREDENTIALS` | גילוי ADC | — | נתיב קובץ JSON קריא של חשבון שירות או ADC נתמך. נתיבים יחסיים נפתרים מתיקיית העבודה. השאירו לא מוגדר לגילוי ADC מקומי או מטא-נתונים. |
| `GOOGLE_CLOUD_QUOTA_PROJECT` | לא מוגדר | — | מזהה או מספר פרויקט צרכן לחיוב ומכסה, הנדרש לקריאות OAuth. חשבון השירות זקוק ל-`serviceusage.services.use` בפרויקט זה. |
| `GOOGLE_MAPS_LANGUAGE` | `en` | `--language` | קוד שפה לתשובות Google התומכות בשפה, בנפרד מבורר שפת המדריך. |
| `GOOGLE_MAPS_TIMEOUT` | `30` | `--timeout` | פסק זמן לבקשה בשניות, מספר שלם 1–600. כולל המתנה, ניסיונות חוזרים, השהיה וקריאת תשובה; להשגת OAuth גבול נפרד באותו ערך. |
| `GOOGLE_MAPS_ENABLED_TOOLS` | הכול (`*`) | `--enabled-tools` | שמות `maps_*` מופרדים בפסיקים או `*`. שמות לא מוכרים מכשילים הפעלה. כלים מושבתים אינם מופיעים בגילוי ולא ניתן לקרוא להם. |
| `GOOGLE_MAPS_MAX_REQUESTS` | `200` | `--max-requests` | תקציב ניסיונות Google HTTP לכל קריאת כלי, מספר שלם 1–10000. משותף לענפים משולבים; ניסיונות חוזרים צורכים מהתקציב. |
| `GOOGLE_MAPS_MAX_RETRIES` | `2` | `--max-retries` | ניסיונות נוספים לכשלים זמניים לכל בקשת Google, מספר שלם 0–5. אפס פירושו ניסיון ראשוני אחד. הניסיונות נשארים בתוך פסק הזמן והתקציב. |
| `GOOGLE_MAPS_TOOL_TIMEOUT` | `120` | `--tool-timeout` | מועד כולל של הכלי בשניות, מספר שלם 1–3600. כולל השגת פרטי גישה, המתנה, קריאות API וניסיונות חוזרים. |

חמש בקשות Google HTTP יכולות לרוץ במקביל בכל תהליך. תקציב הניסיונות מגביל בקשות ולא כסף; בקשת מטריצה אחת יכולה לחייב כמה רכיבים. כלים משולבים מסוימים מחזירים שגיאות לפריט כשענף ממצה תקציב או מועד. ראו [מגבלות ייצור](../guide/production#limits-retries-and-deadlines).

## מאזין HTTP וגישה {#http-listener-and-access}

| משתנה | ברירת מחדל | אפשרות | משמעות וערכים מותרים |
| --- | --- | --- | --- |
| `MCP_HTTP_TOKEN` | לא מוגדר | — | אסימון bearer משותף ללקוחות MCP, הנדרש בהאזנה מחוץ ל-loopback. נפרד מפרטי Google ונדרש גם עם mTLS מובנה. |
| `MCP_HTTP_LISTEN` | `127.0.0.1:3000` | `--listen` | כתובת IP ופורט של המאזין. תמונת Docker מגדירה את ערך הסביבה ל-`0.0.0.0:3000`. |
| `MCP_HTTP_ALLOWED_HOSTS` | מארחי loopback | `--allowed-host` | ערכי HTTP Host מותרים מופרדים בפסיקים. חזרו על האפשרות לכמה ערכים; האפשרויות מחליפות את כל רשימת הקובץ או הסביבה. כללו פורט מתאים. |
| `MCP_HTTP_ALLOWED_ORIGINS` | ללא | `--allowed-origin` | מקורות דפדפן מותרים מופרדים בפסיקים. כותרות Origin קיימות נדחות אלא אם הותרו. ציינו פורטים במפורש; אפשרויות חוזרות מחליפות את הרשימה. |
| `MCP_HTTP_RATE_LIMIT` | `120` | `--rate-limit` | בקשות `/mcp` מאומתות לדקה לכל תהליך, מספר שלם 0–1000000. אפס מבטל. קיבולת ההתפרצות שווה לקצב עם מילוי רציף. |
| `MCP_METRICS_ENABLED` | `false` | `--metrics [true\|false]` | הפעלת Prometheus ב-`/metrics`. `--metrics` ללא ערך פירושו true. משתמש באותו אסימון bearer אם הוגדר, ו-mTLS מובנה חל גם כאן. |
| `MCP_TLS_CERT` | לא מוגדר | `--tls-cert` | תעודת קצה של שרת ב-PEM עם שרשרת ביניים. יש לספק יחד מפתח פרטי תואם. |
| `MCP_TLS_KEY` | לא מוגדר | `--tls-key` | נתיב מפתח פרטי של שרת ב-PEM. שמרו קריא לזהות הריצה ומחוץ למקור ולתמונות. |
| `MCP_TLS_CLIENT_CA` | לא מוגדר | `--tls-client-ca` | חבילת CA ללקוחות ב-PEM המחייבת תעודות לקוח בכל נתיבי המאזין. אינה מחליפה אסימון bearer. |

דלי אסימוני HTTP כללי לתהליך, ולא לכל משתמש או IP. בקשות לא מורשות אינן צורכות ממנו; בריאות ומדדים פטורים. דחייה מחזירה 429 עם `Retry-After`. מגבלת גוף הבקשה היא 1 MiB. ראו [גישת MCP](../guide/mcp#bind-addresses-and-access) ו[תפעול TLS](../guide/production#native-tls-and-mutual-tls).

## אירועי אבחון {#diagnostic-events}

| משתנה | ברירת מחדל | אפשרות | משמעות וערכים מותרים |
| --- | --- | --- | --- |
| `RUST_LOG` | `warn` | — | מסנן יומן אבחון. `info` מפעיל אירועי סיום כלים; ארגומנטים וגופי תשובות Google אינם נרשמים. |
| `MCP_LOG_FORMAT` | `text` | `--log-format` | הערכים `text` או `json`. אבחון נכתב תמיד ל-stderr, ומשאיר stdout ל-JSON של CLI או לתעבורת MCP. |

## בחירת קבצים ובקרות פלט {#file-selection-and-output-controls}

בחירת קובץ מתרחשת לפני שכבות היישום שמעל. `MCP_ENV_FILE` בוחר נתיב dotenv; האפשרות הכללית `--env-file PATH` גוברת עליו. קובץ שנבחר במפורש חייב להתקיים. `--no-env-file` מבטל את כל טעינת dotenv ומתנגש עם `--env-file`. ללא בחירה נקרא רק `.env` האופציונלי בתיקיית העבודה.

גם ערך סביבה ריק במפורש גובר על ערך הקובץ. הוא יכול לנקות אסימון, נתיב TLS או רשימת היתר אופציונליים, אך אינו הופך הגדרה מספרית ריקה לתקינה. ערכי קובץ שנטענו אינם משנים את סביבת התהליך.

`doctor --live` מפעיל במפורש בדיקות העשויות להיות בתשלום; `doctor` רגיל אינו מקוון. `--output PATH` של כלי שומר JSON או PNG גולמי עבור `static-map`. אלה בקרות פקודה ולא הגדרות סביבה נוספות.

שינויי הגדרות יישום וקובצי פרטי גישה דורשים הפעלה מחדש. ב-Linux/macOS יכול SIGHUP לטעון יחד קובצי תעודת TLS מובנה, מפתח ו-CA לקוח; טעינה כושלת שומרת את התצורה הקודמת. ראו [תצורה](../guide/configuration) ו[תפעול ייצור](../guide/production).
