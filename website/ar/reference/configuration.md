# مرجع الإعدادات

تطبق إعدادات التطبيق الـ 21 هذه على CLI وMCP stdio وStreamable HTTP بحسب الحالة. تتبع القيم **الافتراضيات ثم dotenv الاختياري ثم البيئة ثم الخيارات**. راجع [الإعدادات](../guide/configuration) لاختيار الملف ومعاني التجاوز.

تسبق الخيارات العامة الأداة أو `serve`؛ وتأتي خيارات HTTP فقط بعد `serve http`. تعني الشرطة في عمود الخيارات عدم وجود خيار CLI مقابل: احقن القيمة عبر البيئة أو ملف dotenv المحدد.

## الوصول إلى Google وتنفيذ الأدوات {#google-access-and-tool-execution}

| المتغير | القيمة الافتراضية | الخيار | المعنى والقيم المقبولة |
| --- | --- | --- | --- |
| `GOOGLE_MAPS_API_KEY` | غير مضبوط | — | مفتاح Google API مقيّد. مطلوب في وضع `api-key` ولنقاط النهاية الخاصة بالمفتاح في هذا التنفيذ، حتى عند اختيار OAuth. لا يُمرر أبدًا كمعامل أداة. |
| `GOOGLE_MAPS_AUTH_MODE` | `api-key` | `--auth-mode` | القيم `api-key` أو `oauth`. يدعم OAuth واجهات Places (New) وRoutes وWeather وAir Quality وAddress Validation وPlaces Aggregate. |
| `GOOGLE_APPLICATION_CREDENTIALS` | اكتشاف ADC | — | مسار ملف JSON قابل للقراءة لحساب خدمة أو ADC مدعوم. تُحل المسارات النسبية من دليل العمل. اتركه غير مضبوط لاكتشاف ADC المحلي أو البيانات الوصفية. |
| `GOOGLE_CLOUD_QUOTA_PROJECT` | غير مضبوط | — | معرّف أو رقم مشروع فوترة وحصة الاستهلاك، مطلوب لاستدعاءات OAuth. يحتاج حساب الخدمة الإذن `serviceusage.services.use` في ذلك المشروع. |
| `GOOGLE_MAPS_LANGUAGE` | `en` | `--language` | رمز اللغة لاستجابات Google الداعمة للغة، مستقل عن محدد لغة هذا الدليل. |
| `GOOGLE_MAPS_TIMEOUT` | `30` | `--timeout` | مهلة الطلب بالثواني، عدد صحيح 1–600. تشمل الانتظار والإعادات والتراجع وقراءة الاستجابة؛ وللحصول على OAuth حد مستقل بالقيمة نفسها. |
| `GOOGLE_MAPS_ENABLED_TOOLS` | الكل (`*`) | `--enabled-tools` | أسماء `maps_*` مفصولة بفواصل أو `*`. تُفشل الأسماء غير المعروفة البدء. لا تظهر الأدوات المعطلة في الاكتشاف ولا يمكن استدعاؤها. |
| `GOOGLE_MAPS_MAX_REQUESTS` | `200` | `--max-requests` | ميزانية محاولات Google HTTP لكل استدعاء أداة، عدد صحيح 1–10000. مشتركة بين فروع الأدوات المركبة؛ وتستهلك الإعادات محاولات. |
| `GOOGLE_MAPS_MAX_RETRIES` | `2` | `--max-retries` | محاولات إضافية للإخفاقات المؤقتة لكل طلب Google، عدد صحيح 0–5. الصفر يعني محاولة أولية واحدة. تبقى الإعادات ضمن المهلة والميزانية. |
| `GOOGLE_MAPS_TOOL_TIMEOUT` | `120` | `--tool-timeout` | المهلة الكلية للأداة بالثواني، عدد صحيح 1–3600. تشمل الحصول على بيانات الاعتماد والانتظار وطلبات API والإعادات. |

يمكن تنفيذ خمسة طلبات Google HTTP بالتوازي لكل عملية. تحدّ ميزانية المحاولات الطلبات لا التكلفة؛ وقد يفوتر طلب مصفوفة واحد عدة عناصر. تعيد بعض الأدوات المركبة أخطاء لكل عنصر عند نفاد ميزانية فرع أو مهلته. راجع [حدود الإنتاج](../guide/production#limits-retries-and-deadlines).

## مستمع HTTP والوصول {#http-listener-and-access}

| المتغير | القيمة الافتراضية | الخيار | المعنى والقيم المقبولة |
| --- | --- | --- | --- |
| `MCP_HTTP_TOKEN` | غير مضبوط | — | رمز bearer مشترك لعملاء MCP، مطلوب للاستماع خارج loopback. مستقل عن بيانات Google ويظل مطلوبًا مع mTLS الأصلي. |
| `MCP_HTTP_LISTEN` | `127.0.0.1:3000` | `--listen` | عنوان IP للمستمع ومنفذه. تضبط صورة Docker قيمة البيئة إلى `0.0.0.0:3000`. |
| `MCP_HTTP_ALLOWED_HOSTS` | مضيفو loopback | `--allowed-host` | قيم HTTP Host المقبولة مفصولة بفواصل. كرر الخيار لعدة قيم؛ تستبدل الخيارات قائمة الملف أو البيئة كاملة. ضمّن المنفذ المناسب. |
| `MCP_HTTP_ALLOWED_ORIGINS` | لا شيء | `--allowed-origin` | أصول متصفح مسموحة مفصولة بفواصل. تُرفض ترويسات Origin الموجودة إلا إذا سمح بها. حدد المنافذ صراحة؛ وتستبدل الخيارات المتكررة القائمة. |
| `MCP_HTTP_RATE_LIMIT` | `120` | `--rate-limit` | طلبات `/mcp` المصادق عليها في الدقيقة لكل عملية، عدد صحيح 0–1000000. يعطّلها الصفر. سعة الاندفاع تساوي المعدل مع إعادة تعبئة مستمرة. |
| `MCP_METRICS_ENABLED` | `false` | `--metrics [true\|false]` | تفعيل Prometheus على `/metrics`. الخيار المجرد `--metrics` يعني true. يستخدم رمز bearer نفسه عند ضبطه، ويطبق mTLS الأصلي أيضًا. |
| `MCP_TLS_CERT` | غير مضبوط | `--tls-cert` | شهادة خادم PEM مع سلسلة الشهادات الوسيطة. يجب توفيرها مع مفتاح خاص مطابق. |
| `MCP_TLS_KEY` | غير مضبوط | `--tls-key` | مسار مفتاح خادم PEM الخاص. أبقه قابلًا للقراءة بهوية التشغيل وخارج المصدر والصور. |
| `MCP_TLS_CLIENT_CA` | غير مضبوط | `--tls-client-ca` | حزمة CA للعملاء بصيغة PEM لتفعيل شهادات عميل إلزامية في كل مسارات المستمع. لا تحل محل رمز bearer. |

دلو رموز HTTP عام للعملية وليس لكل مستخدم أو IP. لا تستهلك الطلبات غير المخولة سعته؛ وتُستثنى الصحة والمقاييس. يُرجع الرفض 429 مع `Retry-After`. حد جسم الطلب 1 MiB. راجع [وصول MCP](../guide/mcp#bind-addresses-and-access) و[تشغيل TLS](../guide/production#native-tls-and-mutual-tls).

## أحداث التشخيص {#diagnostic-events}

| المتغير | القيمة الافتراضية | الخيار | المعنى والقيم المقبولة |
| --- | --- | --- | --- |
| `RUST_LOG` | `warn` | — | مرشح سجل التشخيص. يفعّل `info` أحداث اكتمال الأدوات؛ ولا تُسجّل المعاملات أو أجسام استجابات Google. |
| `MCP_LOG_FORMAT` | `text` | `--log-format` | القيم `text` أو `json`. يذهب التشخيص دائمًا إلى stderr، ويبقى stdout لنتائج CLI JSON أو حركة MCP. |

## اختيار الملفات والتحكم بالمخرجات {#file-selection-and-output-controls}

يحدث اختيار الملف قبل طبقات التطبيق أعلاه. يختار `MCP_ENV_FILE` مسار dotenv؛ ويعلوه الخيار العام `--env-file PATH`. يجب وجود الملف المحدد صراحة. يعطل `--no-env-file` تحميل dotenv كله ويتعارض مع `--env-file`. دون اختيار، لا يُقرأ سوى `.env` الاختياري في دليل العمل.

ما زالت قيمة البيئة الفارغة صراحة تتجاوز قيمة الملف. يمكنها مسح رمز أو مسار TLS أو قائمة سماح اختيارية، لكنها لا تجعل إعدادًا رقميًا فارغًا صالحًا. لا تغيّر قيم الملفات المحمّلة بيئة العملية.

يختار `doctor --live` مجسات قد تكون قابلة للفوترة؛ و`doctor` العادي غير متصل. يحفظ `--output PATH` للأداة JSON أو PNG خامًا لـ `static-map`. هذه عناصر تحكم بالأمر، وليست إعدادات بيئة إضافية.

تتطلب تغييرات إعدادات التطبيق وملف بيانات الاعتماد إعادة تشغيل. على Linux/macOS، يمكن لـ SIGHUP إعادة تحميل ملفات شهادة TLS الأصلية ومفتاحها وCA العميل معًا؛ وتحافظ الإعادات الفاشلة على الإعدادات السابقة. راجع [الإعدادات](../guide/configuration) و[تشغيل الإنتاج](../guide/production).
