# مهارة الوكيل

تعلّم مهارة `mcp-gmap` المحمولة الوكيل كيفية اختيار الأدوات واستدعاء MCP أو CLI بأمان، وفحص الإخفاقات الجزئية، والحفاظ على نسب المحتوى إلى Google. وهي تكمّل الملف التنفيذي أو اتصال MCP الذي تضبطه بصورة مستقلة.

## التثبيت من المصدر أو من إصدار {#install-from-source-or-a-release}

تتضمن حزمة المصدر وكل أرشيف إصدار [مجلد المهارة](https://github.com/fcenedes/mcp-gmap-rs/tree/main/skills/mcp-gmap). ثبّتها لـ Codex من نسخة المستودع أو الأرشيف المفكوك:

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/mcp-gmap "${CODEX_HOME:-$HOME/.codex}/skills/"
```

استدعها باسم `$mcp-gmap`، مثلًا:

> استخدم $mcp-gmap للعثور على مقاهٍ قرب Gare de Lyon، ومقارنة مسارات المشي، والحفاظ على روابط المصادر.

للوكلاء الآخرين، ضع المجلد نفسه في دليل المهارات المدعوم لديهم، أو حمّل `SKILL.md` والمراجع المرتبطة به. نص التعليمات مستقل عن الوكيل؛ ويوفر `agents/openai.yaml` بيانات اختيارية لواجهة Codex. ثبّت ملفًا تنفيذيًا صالحًا على PATH الخاص بالوكيل أو اضبط [اتصال MCP](./mcp).

## ما الذي تضيفه المهارة {#what-the-skill-adds}

تبدأ المهارة باكتشاف الأدوات، فلا تفترض أن إصدارًا أقدم مثبتًا يعرض أحدث فهرس. وهي تفضّل الإحداثيات الدقيقة ومعرّفات الأماكن المُعادة، وتُبقي نطاق البحث صغيرًا، وتختار الأدوات المخصصة للتحقق من العناوين والأعداد التجميعية والبحث على طول المسار بدل تقريب هذه العمليات من نتائج غير مرتبطة.

تتعامل مع بيانات الاعتماد بوصفها إعدادًا للعملية أو للنشر، وليس معاملات للأدوات. وتفصل بين تفويض MCP الوارد والوصول الصادر إلى Google، وتبدأ بالتشخيص غير المتصل. قد تكون المجسات الحية قابلة للفوترة. ويجب فحص الأخطاء المتداخلة في النتائج المركبة حتى عندما ينجح الاستدعاء الرئيسي.

يوضح [مرجع اختيار الأدوات](https://github.com/fcenedes/mcp-gmap-rs/blob/main/skills/mcp-gmap/references/tool-selection.md) قواعد الاختيار. ويغطي [مرجع CLI](https://github.com/fcenedes/mcp-gmap-rs/blob/main/skills/mcp-gmap/references/cli.md) الاستدعاء المنظم وتشخيص الوصول. راجع [الوصفات](./recipes) في هذا الدليل لسير عمل كاملًا، و[مرجع الأدوات](../reference/tools) لكل معامل.
