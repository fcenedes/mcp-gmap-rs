# الإعدادات

تتشارك CLI ووسيلتا نقل MCP إعدادات بدء التشغيل نفسها. اختر ملفًا للعمل المحلي، وحقن متغيرات البيئة للحاويات، وخيارات لتجاوزات صريحة لكل عملية.

## الأولوية {#precedence}

تُطبَّق القيم بهذا الترتيب، وتكون الأولوية للطبقات اللاحقة:

**القيم المدمجة الافتراضية → ملف dotenv اختياري → بيئة العملية → خيارات CLI**

الملف الافتراضي هو `.env` في دليل العمل الحالي. لا يُبحث في الأدلة الأب. يُسمح بغياب الملف الافتراضي؛ لكن الملف غير المقروء أو غير الصحيح يُفشل البدء دون طباعة محتوياته.

```sh
mcp-gmap-rs --env-file /etc/mcp-gmap/runtime.env serve http
mcp-gmap-rs --no-env-file tools
```

يختار `MCP_ENV_FILE` ملفًا أيضًا، لكن `--env-file` له الأولوية. يجب وجود الملف المحدد صراحة. يعطل `--no-env-file` تحميل الملفات، بما في ذلك `MCP_ENV_FILE`، ويتعارض مع `--env-file`. لا يغيّر تحليل dotenv بيئة العملية.

## تجاوز إعدادات ملف مُركّب {#override-a-mounted-configuration}

```dotenv
GOOGLE_MAPS_LANGUAGE=en
GOOGLE_MAPS_TIMEOUT=30
GOOGLE_MAPS_ENABLED_TOOLS=maps_search_places,maps_place_details
```

مع تركيب ذلك الملف، يغيّر متغير بيئة اللغة ويغيّر خيار المهلة:

```sh
GOOGLE_MAPS_LANGUAGE=fr mcp-gmap-rs \
  --env-file /etc/mcp-gmap/runtime.env --timeout 15 tools
```

تستبدل خيارات `--allowed-host` و`--allowed-origin` المتكررة قوائم الملف أو البيئة المقابلة كاملة. وتتجاوز قيمة البيئة الفارغة صراحة قيمة الملف أيضًا: يمكنها مسح رمز أو قائمة اختياريين، بينما المهلة الفارغة غير صالحة.

## التحكم في الأدوات المتاحة {#control-the-tool-surface}

يقبل `GOOGLE_MAPS_ENABLED_TOOLS` أو `--enabled-tools` أسماء منطقية مفصولة بفواصل مثل `maps_weather,maps_air_quality`، أو `*` لكل الأدوات. تفشل الأسماء غير المعروفة عند البدء. تختفي الأدوات المعطلة من الاكتشاف ولا يمكن استدعاؤها. لا يحتاج الاكتشاف وفحص المخططات إلى بيانات اعتماد، لكن عملية API المطلوبة تحتاج بيانات Google المناسبة.

تُقرأ إعدادات التطبيق عند البدء. أعد التشغيل بعد تغيير قيم البيئة أو JSON لبيانات الاعتماد أو إعدادات Secret/ConfigMap في Kubernetes. تُستثنى ملفات شهادة TLS الأصلية ومفتاحها وCA للعميل: فهي تدعم [إعادة التحميل بـ SIGHUP](./production#native-tls-and-mutual-tls).

راجع [مرجع الإعدادات الكامل](../reference/configuration) لكل الإعدادات الـ 21 وقيمها الافتراضية وخياراتها ونطاقاتها. لا يغيّر اختيار لغة الموقع `GOOGLE_MAPS_LANGUAGE` الذي يتحكم في نص استجابات Google.
